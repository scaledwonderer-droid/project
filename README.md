# FF14 横型IDビジュアル動画ジェネレータ

FINAL FANTASY XIV向けの非公式・非営利ファンツールです。

スクリーンショットとキャラクターデータを組み合わせ、1920×1080・12秒・30fpsの横型IDビジュアル動画をブラウザ内で生成します。

## 主な機能

- 全面スクリーンショット表示
- SS位置・拡大率・左右反転の調整
- メインジョブに応じたジョブマークと外装エンブレム
- Preset A / B / C
- Identity / Origin / Analysis / Access の常時表示
- プレイスタイル分析
- QRコード生成
- 復元用IDコードの生成・復元
- フェード時のSS画像乱れ ON / OFF
- MP4 / H.264優先の12秒動画書き出し
- MP4非対応環境でのWebMフォールバック

## 使い方

1. `index.html`をブラウザで開きます。
2. 背景SSをアップロードします。
3. キャラクター情報、ジョブ、プレイスタイルなどを入力します。
4. プレビュー上でSSの位置や拡大率を調整します。
5. 必要に応じて画像乱れやジョブマーク表示を切り替えます。
6. 「12秒動画を書き出す（MP4優先）」を押します。

## 動作について

- 1920×1080
- 12秒
- 30fps
- 音声なし
- ブラウザ内処理
- Chrome系ブラウザ推奨

MP4 / H.264出力に対応していない環境では、WebMへ自動的に切り替わります。

## データの扱い

アップロードしたスクリーンショットと入力データはブラウザ内で処理されます。

復元用IDコードには、SS画像、キャラクター名、SS位置、SS拡大率、左右反転、QR用URL本文などは保存されません。
