CONTENTS
- job-marks/: 33 jobs × 2 themes = 66 transparent PNG files

- manifest.json: IDs, roles, filenames, and normalized content bounds

IMAGE SPECIFICATION
- Canvas: 1024 × 1024 px
- Format: PNG / RGBA
- Background: fully transparent
- Frame, shadow, and glow: none
- DARK-theme color: #F4F7FA
- LIGHT-theme color: #191D23

IMPLEMENTATION
- Use *-dark.png on dark or image-heavy backgrounds.
- Use *-light.png on light backgrounds.
- Assets are centered by visual centroid and normalized by visible area.
- manifest.json contentBounds can be used for per-job Canvas scale/offset tuning.
